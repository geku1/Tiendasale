# Videojuegos Inteligente

Proyecto académico desarrollado con:

- HTML
- Bootstrap
- CSS
- JavaScript
- Python (Flask)
- Scala
- Prolog

## Funcionalidades

- Consulta de videojuegos
- Ranking de juegos
- Recomendaciones
- Consultas lógicas con Prolog
- Estadísticas con Scala

## Ejecutar API

```bash
cd backend_python
python app.py
```

frontend/index.html
